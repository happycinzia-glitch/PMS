# 專案管理系統

裝修工程 / 設計 / 營造公司適用的內部管理系統，在自己的電腦上執行，資料不外傳。

**第一次使用請先看 [首次設定指南.md](首次設定指南.md)。**

## 快速開始

```bash
npm start          # 或雙擊 啟動系統.bat
```

開啟 <http://localhost:3000/>，預設帳號 `Admin`、密碼 `Admin0000`（**登入後請立刻變更**）。

需要 Node.js 18 以上：`winget install OpenJS.NodeJS.LTS`

## 功能

| 模組 | 內容 |
|---|---|
| 客戶資料 | 新增／修改／刪除、關鍵字查詢、CSV 匯入與範本下載 |
| 廠商資料 | 同上，營業項目可複選、結帳方式 |
| 報價資料 | 明細分大項（各大項小計、合計、稅額、總計）、廠商報價／利潤／利潤%（成本欄可打算式）、依加成算售價、Excel 範本／匯入／匯出、匯入廠商報價、5% 稅金、複製、複製改版、匯出 PDF |
| 專案管理 | 甘特圖進度追蹤、追加減帳（變更單）、專案日誌、結案附件、關聯的應收應付與維修單 |
| 維修工單 | 報修 → 派工 → 完修 |
| 庫存管理 | 料號（MA＋5 碼）、入庫單／領料單、料號與廠商查詢視窗（查無可直接新增）、庫存不足擋領料、庫存報表（期初＋入庫－領料，可匯出 Excel、列印） |
| 應收款項 | 稅額自動 5%、保留款、發票與作廢、請款單 PDF |
| 應付款項 | 憑證類別扣抵規則、所得類別與扣繳、二代健保、支票管理、付款憑証 PDF、AI 發票辨識 |
| 會計維護 | 應收應付收付款登錄、員工薪資（本月發薪、獎金、勞健保與所得稅試算） |
| 公司報表 | 營收結算（損益表）、專案獲利、帳齡分析、營業稅 401、扣繳彙總，皆可匯出 CSV |
| 資產管理 | 公司設備清冊（CA＋5 碼）：品名、廠商（可查詢）、規格、部門、管理人、購入／報廢日期、金額；填報廢日期即標示「已報廢」（需會計權限） |
| 帳號管理 | 九種功能權限、帳號鎖定與解鎖、薪資設定、備註 |
| 門禁帳號 | 系統登入頁之前的外層門禁：獨立登入頁、門禁帳號維護、開關（限系統管理者） |
| 項目維護 | 八組下拉清單自行增刪，不需改程式 |
| 操作紀錄 | 最近 1000 筆寫入動作（不含查詢與密碼內容） |
| 備份設定 | 自動備份：設定每天／每週／每月的時間與保留份數，備份到 Google 雲端硬碟或本機資料夾；可立即備份、測試連線 |
| 系統還原 | 從備份檔還原，執行前自動下載目前資料的備份 |

首頁另有待辦提醒：應收應付逾期與將到期、支票到期、專案階段逾期、驗收中、保固將到期。

## 資料存放

| 路徑 | 內容 |
|---|---|
| `data/db.json` | 全部資料（21 張表）。**備份＝複製整個 `data` 資料夾** |
| `data/files/` | 結案附件實體檔，依專案編號分資料夾 |
| `data/session-secret.txt` | 登入簽章金鑰，首次啟動自動產生 |

不需要安裝資料庫伺服器，也不需要設定連線。

### 改用 Neon 資料庫（線上版必備）

設定 `DATABASE_URL` 後，資料改存 PostgreSQL（自學講義第 5 章用 Neon 免費方案），
第一次連線時自動建立資料表（每類資料一張，例如 `customers`、`quotes`），沒設定就維持存 `data/db.json`。

```bash
node tools/import-db.js            # 把 data/db.json 匯入資料庫（資料庫已有資料時要加 --force 才會覆蓋）
node tools/import-db.js 備份.json  # 也可以匯入「系統還原」用的備份檔
```

- 寫入類操作要等資料確實寫進資料庫才會回應；資料庫連不上時畫面會顯示「這次的修改沒有儲存」，且真的不會存。
- 本機版和線上版可以連同一個資料庫。兩邊幾乎同時修改時，後到的那一筆會被擋下並請使用者重新整理再做一次，不會互相覆蓋。
- 結案附件的實體檔仍存在 `data/files/`，線上版要等第 6 章改存 Google 雲端硬碟才不會因重新部署而消失。

## 環境變數（皆可省略）

| 變數 | 預設 | 說明 |
|---|---|---|
| `PORT` | `3000` | 服務埠號 |
| `DATABASE_URL` | 無 | PostgreSQL（Neon）連線字串。設定後資料改存資料庫，見上方「改用 Neon 資料庫」 |
| `PMS_DATA_DIR` | `./data` | 資料存放位置（未設定 `DATABASE_URL` 時的 `db.json`，以及結案附件） |
| `ADMIN_ID` / `ADMIN_PASSWORD` / `ADMIN_NAME` | `Admin` / `Admin0000` / 系統管理員 | 僅在資料庫**完全沒有帳號**時，用於建立第一個管理者 |
| `SESSION_SECRET` | 自動產生 | 不設定則首次啟動產生亂數並存檔 |
| `ANTHROPIC_API_KEY` | 無 | AI 發票辨識功能 |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` / `GOOGLE_REFRESH_TOKEN` / `GOOGLE_FOLDER_ID` | 無 | 自動備份到 Google 雲端硬碟用（取得方式見自學講義第 6 章） |
| `BACKUP_KEY` | 無 | 設定後可用外部排程服務打 `/api/backup/trigger?key=…` 觸發備份 |
| `APP_TZ` | `Asia/Taipei` | 伺服器時區（日期、報表歸期與備份排程時間都以此為準） |
| `GATE_OFF` | 無 | 設為 `1` 暫時略過門禁（忘記門禁密碼時的緊急用途） |

## 技術

Node.js + Express，資料存單一 JSON 檔（寫入採 tmp + rename 原子替換），或設定 `DATABASE_URL` 改存 PostgreSQL，
密碼以 scrypt 雜湊，登入採 session cookie（8 小時逾時），連續錯誤 5 次鎖定帳號。

**相依套件只有 `express`、`express-session` 與 `pg`（純 JavaScript 的資料庫連線套件），不含任何原生模組**，
整個資料夾可直接複製或壓縮搬到別台電腦（含 Mac / Linux）執行。
報價單與庫存報表的 Excel 功能用的是前端的 SheetJS（`public/vendor/xlsx.full.min.js`，靜態檔、登入後用到時才載入），不需安裝套件。

## 安全性提醒

這套系統設計為**公司內部網路使用**，沒有 HTTPS 加密，也未針對公開網際網路做防護。
請勿直接架設在對外的伺服器上。

前端程式（`app.html`、`app.js`、流程圖）必須登入後才能下載，未登入只看得到登入頁。
要讓外人連系統登入頁都看不到，請到「門禁帳號」開啟門禁（見首次設定指南第六章）。
已登入的使用者仍可存下前端程式；網路層的保護（VPN、Cloudflare Access、IP 白名單）
效果更好，並請確認 GitHub 儲存庫設為 Private。

`data/db.json` 內含所有營運資料與密碼雜湊，備份檔請比照機密文件保管。
